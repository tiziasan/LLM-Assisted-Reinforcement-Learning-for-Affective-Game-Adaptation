## LLM-Assisted-Reinforcement-Learning-for-Affective-Game-Adaptation

This is the supplemental material for the paper "LLM-Assisted Reinforcement Learning for Affective Game Adaptation"
- A pdf file called Supplementary Evaluation and Statistical Analyses.pdf that contains Evaluation and statistical analyses
- The folder Cubewars contains the code for Cubewars game with the relative instructions to install it
- The folder adaptive system contains the code for the Model-Free Reainforcement Learning algorithm, the MFRL + LLM, and the server to comunicate with the game, with the installation instruction
- The folder data contains the questionnaires data from the 46 participants and the raw experiment data for each of the participants.
